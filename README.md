# 🛍️ Jastip Nura

<img src="https://raw.githubusercontent.com/mrisqikhasani/jastip-nura/refs/heads/main/storage/app/public/jastipnura.png" alt="Jastip Nura Web App" />

**Jastip Nura** is a Laravel-based e-commerce website that provides **personal shopper (jastip) services from Thailand**, delivering products across Indonesia — including **Papua** and **Yogyakarta**. The platform focuses on affordable and trendy **women’s products**, offering a smooth shopping experience from browsing to checkout.

---

## 🚀 About the Project

Jastip Nura was built to simplify the process of ordering Thailand-based products without the hassle of international purchasing. Users can browse curated catalogs, add items to cart, checkout easily, and upload payment proof — all in a clean and minimalist interface.

The project uses **Laravel Blade** and follows a simple yet scalable architecture, making it suitable for small-to-medium e-commerce use cases.

---

## ✨ Key Features

* 🔐 **Authentication System**
  Secure **login & signup** for users.

* 🛒 **Shopping Cart & Checkout**
  Add products to cart, checkout seamlessly, and upload **payment proof**.

* 🧾 **Order Management**
  Users can view their **order history** and order status from their account dashboard.

* 👤 **Account Management**
  Manage profile data, delivery address, and personal information.

* 🗂️ **Product Catalog with Filtering**

  * Filter products by category
  * Search products using a **JavaScript-powered search bar**

* 🎨 **Minimalist & Consistent UI**
  Clean, modern, and easy-to-use design with a consistent color palette.

* 👥 **Multi-User Roles**

  * **Admin**
  * **Buyer / Customer**

* 🛠️ **Admin Panel with Laravel Filament**
  Powerful admin dashboard to manage:

  * Users
  * Products
  * Orders

---

## 🧴 Product Focus

Jastip Nura specializes in **women’s products**, including:

* Skincare
* Bodycare
* Tops (Atasan)
* Bottoms (Bawahan)

All products are offered with **competitive and varied pricing**.

---

## ⚙️ Tech Stack

* **Framework:** Laravel
* **Frontend:** Blade, Tailwind CSS, JavaScript
* **Admin Panel:** Laravel Filament
* **Database:** MySQL
* **Authentication:** Laravel Auth
* **Local Development:** Laragon (Windows)
